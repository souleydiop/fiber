Guide d'utilisation

📥 Importer des fichiers

PDF OTDR Viavi / EXFO
Formats .pdf avec rapports OTDR. Le parser détecte automatiquement Viavi (SOR) et EXFO.
→ Onglet Mesures · multi-fichiers acceptés.

KML / KMZ — Tracé fibre
Exporter depuis Google Earth ou QGIS. Les sections (LineString) forment le réseau.
→ Onglet Sections une fois importé.

KMZ — Base sites (BTS/POP)
Placemark avec coordonnées GPS. Noms identiques aux champs Origine/Extrémité des PDF.
→ Utilisé pour la corrélation automatique.

Excel (.xlsx / .xls)
Inventaire de ports fibre avec distances optiques et dégradations.
→ Colonnes : Port, Distance Optique (Km), état FO, points de dégradation.

🗺️ Corrélation OTDR → Carte

1. Importe un PDF OTDR + un KMZ Sites + un KML Tracé.
2. Onglet Mesures → sélectionne une mesure.
3. Renseigne Origine et Extrémité (noms des sites).
4. Appuie sur Corréler → les événements OTDR sont placés sur le tracé.
5. Les points rouges = anomalies à vérifier sur le terrain.

📍 Sonde de distance

Depuis la carte, appuie sur un point du tracé pour mesurer la distance optique depuis l'origine.
Utile pour localiser un événement OTDR physiquement sur le câble.

🔍 Recherche de site

Carte → bouton 🔍 Site → tape le nom d'un site BTS/POP pour centrer la carte dessus.

📏 Waypoints manuels

Si la corrélation automatique échoue (tracé non disponible), ajoute des waypoints manuels pour guider l'itinéraire.
→ Bouton + Waypoint dans le détail d'une mesure.

⚠️ Lecture des événements

Rouge = perte d'épissure ou réflectance hors seuil.
Distance = position depuis l'origine du câble.
AFF. = affaiblissement (dB) · RÉFL. = réflectance (dB)
BILAN = perte cumulée depuis le départ.
